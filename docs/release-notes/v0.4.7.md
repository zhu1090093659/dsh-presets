The preset center publishes from its own repository on the aligned version. This release advances the plugin cohort to the family's `0.2.1-rc.2` SDK and brings the browser half's shared module table along with it.

> **Important change**: no manual migration is needed, and no persisted identifier, wire-protocol field or profile format was renamed. The package name `@linxin666/dsh-client-ui-preset-center` and its install path are unchanged: a downloaded composition stays inert until the plugin declares it to the agent-preset registry. One host requirement does change: the `@deepseek-ai/dsh` peer dependency and the plugin's declared engines both move to `>=0.2.1-rc.2`, so older hosts no longer satisfy this plugin's load condition.

### Other Changes

- DSH version requirement: the minimum host version in `peerDependencies` and `dsh.engines` moves from `>=0.1.7-rc.1` to `>=0.2.1-rc.2`, sharing one SDK cohort with the rest of the family; the version badge in the READMEs follows
- Shared module table: the shared module list used by the browser-half build follows the `0.2.1-rc.2` cohort and gains the `zod` and `@tanstack/react-virtual` rows
- Repository documentation: a repository-level `AGENTS.md` and the `.agents/notes` decision-record structure are added; they only affect in-repo collaboration and do not change the package content
