预设中心随 dsh-web 家族对齐到统一版本 0.4.21，与全家桶同版本发布；本区间没有任何源码或内容改动，运行时行为与 0.4.20 完全一致。

> **兼容性**：没有破坏性变更；`dsh.engines.dsh`、peer 与 engines 下限、包名、导出面、持久化标识与线协议均未改，0.4.20 可直接升上来，也可直接退回，不需要迁移数据。

### 其他改动

- 版本对齐：`package.json` 的 `version` 从 0.4.20 改为 0.4.21，卫星先发、主仓随后跟上同号。
