预设中心以对齐版本从独立仓库发布。本版本带上挂载重放修复与 README 的工坊展示更新。

> **重要变更**：本版本没有需要手工迁移的改动，没有重命名任何已持久化的标识符、线协议字段或 profile 格式。包名 `@linxin666/dsh-client-ui-preset-center` 与安装方式不变：下载的预置组合在插件显式声明前保持惰性，不会自动进入 agent 的预置注册表。

### 修复

- 上一次挂载尚未释放时被拒绝的挂载不再丢失：持有者退出后自动重放，插件不会停留在未挂载状态

### 其他改动

- README：展示工坊上最受欢迎的三个预置组合

The preset center publishes from its own repository on the family's aligned version. This release carries the mount replay fix and the README Workshop showcase.

> **Important change**: no manual migration is needed, and no persisted identifier, wire-protocol field or profile format was renamed. The package name `@linxin666/dsh-client-ui-preset-center` and its install path are unchanged: downloaded preset combinations stay inert until a plugin declares them and never enter an agent's preset registry on their own.

### Bug Fixes

- A mount refused while the previous holder was still alive is no longer lost: it replays once the holder exits, so the plugin never stays unmounted

### Other Changes

- README: showcase the three most-liked Workshop presets
