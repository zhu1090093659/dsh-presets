预设中心以对齐版本从独立仓库发布。本仓库持有社区预设管理器（工坊的 Presets 面板与安装、声明、停用、卸载预置的宿主库）以及 `presets/` 目录。从本版本起，四个卫星仓与本仓发布同一个 X.Y.Z，卫星先发、本仓后发；包版本从 0.4.1 移到 0.4.2 是这次对齐的结果。

> **重要变更**：本版本没有需要手工迁移的改动，没有重命名任何已持久化的标识符、线协议字段或 profile 格式。包名 `@linxin666/dsh-client-ui-preset-center` 与安装方式不变：下载的预置组合在插件显式声明前保持惰性，不会自动进入 agent 的预置注册表。

### 其他改动

- 独立仓库：预设中心与 `presets/` 目录单独评审、单独发版
- CI 与 tag 触发的发布管线（版本与 tag 一致性校验、registry 传播断言、GitHub Release）

<summary>English</summary>

The preset center releases from its standalone repository at the aligned version. This repository holds the community agent-preset manager (the Workshop's Presets panel and the host library that installs, declares, disables and uninstalls presets) together with the `presets/` directory. From this release on, the four satellite repositories publish the same X.Y.Z as this repository, satellites first; the package moves from 0.4.1 to 0.4.2 as that alignment.

> **Important change**: no manual migration is needed, and no persisted identifier, wire-protocol field, or profile format is renamed. The package name `@linxin666/dsh-client-ui-preset-center` and the install path are unchanged: a downloaded composition stays inert until the plugin declares it, so it never enters the agent's preset registry on its own.

### Other Changes

- Standalone repository: the preset center and the `presets/` catalog are reviewed and released here
- CI and a tag-triggered release pipeline (package/tag version agreement, a registry propagation assertion, and the GitHub Release)
